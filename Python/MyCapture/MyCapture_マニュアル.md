# MyCapture ユーザーマニュアル

Python製のスクリーンショット常駐ツールです。ホットキー一発で、範囲選択・全画面・アクティブウィンドウのスクショを撮り、**日時秒ベースのファイル名で自動保存**します。上書き確認は一切出ません。

---

## 1. これは何をするツールか

- ホットキーを押すと画面をキャプチャして、指定フォルダへ自動保存する
- ファイル名は `capture_20260720_143025.png` のように **日時＋秒** で付くため、常に別名になり衝突しない
- 保存時に「上書きしますか？」のダイアログが出ない
- 3つのキャプチャモードを備える
  - **範囲選択** … マウスでドラッグした矩形を撮る
  - **全画面** … 全モニタ全体を撮る
  - **アクティブウィンドウ** … 最前面のウィンドウだけを撮る

---

## 2. 動作要件

| 項目 | 内容 |
|------|------|
| OS | Windows 10 / 11 |
| Python | 3.8 以上（3.10 以降推奨） |
| 追加ライブラリ | **Pillow**（画像の取得・保存に使用） |

`tkinter`（GUI）や `ctypes`（ホットキー・DPI対応）は Python 標準機能なので、追加インストールは不要です。

---

## 3. インストール手順

### 3-1. Python の確認

コマンドプロンプトを開いて、次を実行します。

```
python --version
```

`Python 3.x.x` と表示されればOKです。表示されない場合は [python.org](https://www.python.org/) からインストールし、インストール時に **「Add python.exe to PATH」にチェック** を入れてください。

### 3-2. Pillow のインストール

```
pip install pillow
```

これだけで準備完了です。

### 3-3. ファイルの配置

`pycapture.py` を任意のフォルダに置きます。本マニュアルでは以下を前提とします。

```
C:\work\MyCapture\pycapture.py
```

---

## 4. 起動方法

### 4-1. 手動で起動（動作確認用）

まずは黒いコンソール付きで起動して、正常に動くか確認します。

```
python C:\work\MyCapture\pycapture.py
```

小さなコントロールウィンドウが最前面に表示されれば成功です。

### 4-2. コンソールを出さずに起動（通常運用）

GUIアプリなので、普段は黒い窓を出さずに起動します。`C:\work\MyCapture\MyCapture.bat` を作り、中身を次のようにします。

```bat
@echo off
start "" pythonw "C:\work\MyCapture\pycapture.py"
```

`pythonw.exe` はコンソールを持たない Python 実行体（`python.exe` と同じフォルダにあります）です。このバットをダブルクリックすると、黒い窓なしでGUIだけが立ち上がります。

> **メモ**：`pythonw` はエラーが出ても何も表示せず黙って終了します。挙動が不安定なうちは `python`（コンソールあり）で確認し、問題なく動くのを見届けてから `pythonw` に切り替えると安全です。

### 4-3. ログイン時に自動起動（任意）

1. `MyCapture.bat` を右クリック →「ショートカットの作成」
2. `Win + R` を押して `shell:startup` と入力 → Enter（スタートアップフォルダが開く）
3. 作ったショートカットをそのフォルダに入れる

これでWindowsにログインするたびに自動で常駐します。

## 5. 使い方

### 5-1. ホットキー

ツールが起動している間、どのアプリで作業していても次のキーで撮れます。

| ホットキー | 動作 |
|-----------|------|
| **Ctrl + Alt + 1** | 範囲選択キャプチャ |
| **Ctrl + Alt + 2** | 全画面キャプチャ |
| **Ctrl + Alt + 3** | アクティブウィンドウキャプチャ |

コントロールウィンドウ上のボタンからも同じ操作ができます。

### 5-2. 範囲選択の操作

`Ctrl + Alt + 1`（またはボタン）を押すと、画面全体が半透明の暗いオーバーレイに覆われます。撮りたい範囲を**マウスでドラッグ**し、ボタンを離すとその矩形が保存されます。

- 途中でやめたいときは **Esc** キー、またはドラッグせずにクリックするとキャンセルされます。

### 5-3. 保存先・ファイル名の設定

コントロールウィンドウで以下を設定できます。

- **保存先**：「変更」ボタンで保存フォルダを選択
- **接頭辞**：ファイル名の頭に付く文字列（既定は `capture`）
- **形式**：`png` / `jpg` / `bmp` から選択

「フォルダを開く」ボタンで、現在の保存先フォルダをエクスプローラーで開けます。

---

## 6. ファイル名のルール

保存されるファイル名は次の形式です。

```
<接頭辞>_<年月日>_<時分秒>.<拡張子>
例) capture_20260720_143025.png
```

秒単位まで名前に入るので、通常はファイル名が重複しません。万一、同じ秒に連続で2枚撮った場合のみ、末尾にミリ秒3桁が付いて衝突を回避します。

```
例) capture_20260720_143025_812.png
```

---

## 7. 保存形式と画質について

| 形式 | 圧縮 | 画質 | 特徴 |
|------|------|------|------|
| **PNG**（推奨） | 可逆 | 劣化なし | 元画像とドット単位で同一。文字もくっきり。スクショに最適 |
| **BMP** | 無圧縮 | 劣化なし | 完全無圧縮。見た目はPNGと同じだがファイルが非常に大きい |
| **JPG** | 非可逆 | わずかに劣化 | ファイルは小さいが、文字のフチにノイズが出やすい |

**スクリーンショット用途では PNG が最もおすすめ**です。可逆圧縮なので画質の劣化がなく、サイズもBMPより小さく収まります。

JPGを使う場合、本ツールは劣化を最小化するため **quality=100・色間引きオフ（4:4:4）** で保存します。ただし quality=100 でもJPEGは仕組み上わずかに劣化する点は変わりません。画質を優先するならPNGを選んでください。

---

## 8. 設定の保存場所

保存先・接頭辞・形式の設定は、次のファイルに自動で記録されます。

```
C:\Users\<ユーザー名>\.pycapture_config.json
```

次回起動時にこの内容が読み込まれるので、毎回設定し直す必要はありません。設定をまっさらに戻したいときは、このファイルを削除すれば初期状態で起動します。

## 9. トラブルシューティング

### 「Error: Can't register hotkey!」に相当する警告が出る／ホットキーが効かない

指定のホットキー（Ctrl+Alt+1〜3）が **他のアプリに先に取られている** ときに起きます。ステータス欄に警告が出ますが、**GUIのボタンからは通常どおり撮れます**。原因アプリ（画面キャプチャ系ツール、GeForce のオーバーレイ、常駐ソフトなど）を終了するか、そのアプリ側のホットキー設定を変更してください。

### 起動しても何も表示されず、すぐ終わる

`pythonw` で起動している場合、エラーがあっても画面に出ずに落ちます。一度 `python`（コンソールあり）で起動して、表示されるエラーメッセージを確認してください。多くは **Pillow 未インストール**（`pip install pillow` で解決）が原因です。

### 範囲選択でキャプチャ位置が数ピクセルずれる

モニタごとに拡大率が異なるマルチモニタ環境（例：ノート150%＋外部100%）だと、座標が数ピクセルずれることがあります。すべてのモニタの拡大率を揃えると解消します。単一拡大率の環境では問題ありません。

### 保存できない／フォルダが無いと言われる

保存先フォルダは自動で作成されますが、書き込み権限のない場所（システムフォルダ等）を指定すると失敗します。ドキュメントやデスクトップ配下など、書き込み可能な場所を指定してください。

## 10. 補足・注意事項

- 本ツールは**個人環境での利用を想定**しています。業務用PCへ導入する場合は、スクリーンショットの取り扱いや常駐ツールの実行が社内のセキュリティポリシーに抵触しないか、事前に確認してください。
- Pythonが入っていない環境へ配布したい場合は、`pyinstaller` で単体exeに固められます。

  ```
  pip install pyinstaller
  pyinstaller --onefile --noconsole pycapture.py
  ```

  `dist\pycapture.exe` が生成され、ダブルクリックで起動できるようになります。
