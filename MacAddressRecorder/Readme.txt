この度は『MAC ADDRESS RECORDER』をご使用いただき誠にありがとうございます。
このソフトは総合電子専門学校平成５年度卒業生を対象に
住所録、個人情報を管理する事が出来るツールです。
容易に情報の追加、編集、削除が出来ることにより
誰でも簡単にお友達の近況を管理できます。

■機能

(1)個人情報の追加
　　他のお友達を登録したい時に個人情報を追加できます。
　　[メニュー]→[個人情報の追加]　を行ってください。
　　画像は無くても登録可能です。画像が用意できる場合は
　　縦120×横100ﾋﾟｸｾﾙのサイズのjpeg画像を Imageフォルダの配下へ
　　置いて登録時に画像のファイル名(***.jpg)を指定してください。

　　├ 100pic ┤
　　┌────┐┬
　　│　　　　││
　　│ＪＰＥＧ│
　　│　　　　│120pic
　　│　　　　│
　　│　　　　││
　　└────┘┴

(2)個人情報の編集
　　現状登録されているお友達の情報を編集できます。
　　[メニュー]→[個人情報の編集]　を行ってください。
　　現在未対応です。

(3)個人情報の削除
　　現状登録されているお友達の情報を削除できます。
　　[メニュー]→[個人情報の削除]　を行ってください。

(4)お誕生日お知らせ機能
　　お誕生日になると個人プロフィールの誕生日欄が赤くなり
　　誕生日を教えてくれます。

(5)時計機能
　　このソフトの一番したのステータスバーに日付と現在時刻が
　　表示されます。この日付と現在時刻は使用するパソコンの時刻に
　　依存します。時計を合わせたい場合はパソコンの時計を修正してください。

(6)メール起動機能
　　アプリケーション中の「メール」ボタンをクリックするとOutLookExpressが
　　起動するようになっています。

※尚、初期値で入っている情報は分かっている範囲内です。
　　　あまりにも適当なので間違っていたらごめんなさい。

■インストール
　各個人でディレクトリを作成していただき、そこへ解凍してご使用ください。
　スタートアップ、スタートメニューには登録されません。

■アンインストール
　mac_addressr.exeのあるディレクトリをそのまま削除してください。
