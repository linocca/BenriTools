# 通知転送くん (NotifyForwarder)

スマホに届いた通知(LINEなど、全アプリ対象)を検知して、
設定した電話番号にSMSで「〇〇に通知が届きました」と送るアプリです。

## できること
- 全アプリの通知を検知(特定アプリを除外する設定画面あり)
- 通知が来たアプリ名だけをSMSまたはメールで送信(本文などプライバシーに関わる内容は送りません)
- 送信方法は「SMSのみ」「メールのみ」「両方」から選択可能
- 同じアプリから短時間に何度も通知が来ても、30秒に1回までに制限(スパム防止)
- 電話アプリ(標準ダイヤラ)からの通知は「電話が来ました」という専用メッセージになります

## 必要なもの
- Android Studio (無料。https://developer.android.com/studio からダウンロード)
- 通知を検知する側のスマホ(実機。USBケーブルでPCと接続してインストールします)
- そのスマホにSIMが入っていて、SMS送信ができる回線であること

## セットアップ手順

1. **Android Studioをインストール**(まだの場合)

2. **このフォルダをAndroid Studioで開く**
   - 「Open」からこのフォルダ(NotifyForwarder)を選択
   - 初回はGradleの同期が走ります。Gradle Wrapperの作成を提案されたら
     そのまま「OK」で進めてください
   - 初回のビルドはライブラリのダウンロードで数分かかることがあります

3. **スマホをUSBデバッグモードにしてPCに接続**
   - スマホの「設定 > 端末情報 > ビルド番号」を7回連打して開発者向けオプションを有効化
   - 「設定 > システム > 開発者向けオプション > USBデバッグ」をON
   - USBケーブルでPCと接続(「このパソコンを許可しますか」のダイアログが出たら許可)

4. **Android Studioの「Run」ボタン(緑の再生マーク)を押す**
   - 接続したスマホが実行先に選ばれていることを確認して実行
   - スマホに「通知転送くん」がインストールされます

5. **アプリを起動して初期設定**
   - 送信方法(SMSのみ/メールのみ/両方)を選ぶ
   - SMSを使う場合: 電話番号を入力
   - メールを使う場合: 下記の手順で取得した「Googleアプリパスワード」と、
     送信元Gmailアドレス・送信先メールアドレスを入力
   - 入力したら画面下の「保存」を押す
   - 「通知アクセス設定を開く」を押し、一覧から「通知転送くん」を探してONにする
   - SMSを使う場合のみ:「SMS送信の許可をリクエスト」を押して許可する
   - 画面下部のステータスが両方「OK」になっていればセットアップ完了です

### Googleアプリパスワードの取得方法(メール送信を使う場合)

Gmailアカウント自体のパスワードではなく、アプリ専用の16桁のパスワードが必要です。

1. 送信元にしたいGoogleアカウントで https://myaccount.google.com/apppasswords を開く
   (2段階認証が有効になっている必要があります。無効な場合は先に2段階認証を設定してください)
2. アプリ名を適当に入力(例: 通知転送くん)して「作成」
3. 表示された16桁のパスワード(スペースは除いて入力)を、アプリの
   「Googleアプリパスワード」欄にそのまま入力する

6. **動作確認**
   - LINEなど何かアプリに通知が来ると、設定した電話番号宛てに
     「(アプリ名)に通知が届きました」というSMSが届きます

7. **不要な通知を除外したいとき**
   - アプリのトップ画面で「除外するアプリを設定」を押す
   - 一覧(検索ボックスで絞り込み可能)から、SMSを送ってほしくないアプリに
     チェックを入れて「保存」
   - 例: キーボードアプリ(Gboardなど)の内部的な通知は重要でないことが多いので、
     気になる場合はチェックを入れて除外してください

## 注意点
- 機種によっては(特にXiaomi、OPPO、HUAWEIなど)バッテリー最適化の設定により、
  バックグラウンドで通知検知サービスが止められてしまうことがあります。
  その場合は「設定 > 電池 > このアプリの電池最適化を無効にする」のような
  設定を追加で行ってください。
- SMS送信には通常の通信キャリアの料金がかかります(国内なら多くのプランで
  無料〜数円程度)。
- 特定のアプリだけ除外したい、通知内容をもっと詳しくしたい、といった
  カスタマイズが必要であれば、いつでも追加対応できます。
